RSA Virtual Laboratory

RSA Algorithm — Interactive Secure Communication between Alice and Bob. Alice and Bob each generate their own RSA key pair from primes you choose. Whenever one of them sends a message, it is scrambled with the receiver's public key and can only be unscrambled with the receiver's private key — so only the intended reader can ever read it, even though the scrambling method itself is public knowledge.

Sample Experiment (fixed reference)

This worked example never changes, however you fill in the form below — it's here so you can check your own results against it.

p = 5, q = 11, e = 3
n = 5 × 11 = 55
φ(n) = (5−1)(11−1) = 40
d = 27 (27 × 3 mod 40 = 1)
Public key PU = (3, 55)
Private key PR = (27, 55)
M = 7 → C = 7³ mod 55 = 343 mod 55 = 13
Decrypt: 13²⁷ mod 55 = 7 ✓

Character mapping

Every letter is converted to a number before it can be encrypted: A = 0, B = 1, C = 2, … Z = 25. A space is left exactly as it is and passed straight through, unencrypted — it never becomes a number. This letter-by-letter mapping is a teaching visualisation, not how production RSA encodes real messages.
